# «Армия спорта», первый этап — презентация для клиента

Отдельная страница kupdasha.ru/armysport (Тильда, страница без общей шапки и подвала), к основному сайту kupdasha.ru не относится.
Оформление — как у кейсов сайта: белый фон, Golos Text, крупные строчные заголовки, черные кнопки.

## Файлы
- `as.js` — вся страница: тексты, главы трех путей (первая — преемственность, вторая — движение, альтернатива — только слово), живые блоки: компоновки знака и фон, пресс-волл, монеты (лупа, смена кадров), стеклянная звезда (шейдер из макета иконки), награды и монеты в 3D на model-viewer по кнопке.
- `as.css` — оформление; `index.html` — локальный просмотр и скелет загрузки (build.py берет скелет оттуда).
- `img/` — картинки (webp, -s — 820 px для телефона), SVG знаков, модели .glb и studio.hdr. Выгружены из «Армия спорта.fig» своим рендером.
- `fonts/` — Golos Text и Spectral, только нужные начертания.
- `build.py` → `tilda-block.txt` — блок «HTML-код» для Тильды: скелет и загрузчик с jsDelivr по номеру последнего коммита.
- `publish.sh "что изменилось"` — собрать блок, отправить на GitHub, прогреть jsDelivr. Блок в Тильде не перевставлять.

## Правила
Без оранжевого, без «·», без нумерации «01/02», без фейковых цифр, капса (кроме самих логотипов), эмодзи, текста мельче 16 px, стекла и неона в интерфейсе. Кнопки с заливкой, строчные; контурные — только теги. Текста минимум — иллюстрировать.
